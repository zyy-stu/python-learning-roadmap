# Python 变量练习

通过终端输出或函数返回指定结果。题面给出固定输入时，先验证固定输入，再改变数据验证一般行为。

## 基础题

1. 交换 a=2、b=7，输出两个新值。

2. 同时绑定 x=3、y=4，输出和。

3. 先绑定数量 2，再把数字改成字符串 '2 件'，输出类型名。

4. 判断 class 是否为关键字。

5. 判断 item_count 是否符合标识符形式。

## 进阶题

6. 给同一个列表绑定两个名称，从第二个名称追加 8，输出第一个列表。

7. 对 [4] 调用 copy，判断两个对象的 id 是否相同。

8. 模块变量 total=10，函数使用同名局部变量 3，返回两个值。

## 综合题

9. 商品每件 12 元、买 3 件、运费 5 元，分开绑定三项后计算总价。

10. 库存中苹果 5、梨 2，用不同变量记录售出苹果 3 件后的两种库存。
