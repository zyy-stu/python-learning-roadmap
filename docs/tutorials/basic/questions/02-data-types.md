# Python 基本数据类型练习

通过终端输出或函数返回指定结果。题面给出固定输入时，先验证固定输入，再改变数据验证一般行为。

## 基础题

1. 输出 7 的类型名称。

2. 将文本 '42' 转成整数。

3. 输出 2+3j 的虚部。

4. 判断空列表的布尔值。

5. 返回 None 的类型名。

## 进阶题

6. 检查 True 是否是 int 的实例。

7. 把 (2, 4) 转成列表并添加 6。

8. 将字符串 '3.50' 转成浮点数和整数字段 2 相乘。

## 综合题

9. 解析端口 '8080' 和开关 'false'，输出 (端口整数, 开关布尔值)。

10. 缺失用户昵称以访客代替，已有空字符串保留，输出两种结果。
