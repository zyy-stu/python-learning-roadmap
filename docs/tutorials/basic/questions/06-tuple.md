# Python 元组 tuple练习

通过终端输出或函数返回指定结果。题面给出固定输入时，先验证固定输入，再改变数据验证一般行为。

## 基础题

1. 创建仅包含 5 的元组。

2. 将 [1, 2] 转成元组。

3. 取 (8, 9, 10) 的末项。

4. 取 (5, 6, 7, 8) 中间两项。

5. 统计 (1, 2, 1) 中 1 的次数。

## 进阶题

6. 解包 1, 2, 3, 4，返回头、中间列表、尾。

7. 在元组 ([2],) 内部的列表追加 3。

8. 在 ('a', 'b', 'a') 中找第一个 'a' 的位置。

## 综合题

9. 以坐标 (2, 4) 为键存储并查询 '已占用'。

10. 遍历两个 (商品, 数量) 元组，返回数量总和。
