# Python 字典 dict练习

通过终端输出或函数返回指定结果。题面给出固定输入时，先验证固定输入，再改变数据验证一般行为。

## 基础题

1. 创建 name='小林' 的字典并读取 name。

2. 在 {'a': 1} 中读取缺失的 b，默认返回 0。

3. 把 {'a': 1} 中 a 改为 3 并添加 b=2。

4. 用 pop 取出 a，返回旧值和剩余字典。

5. 取得 {'a': 1, 'b': 2} 的键值对列表。

## 进阶题

6. 用字典推导式建立 1 到 3 的平方映射。

7. 从 {'用户': {'分数': 90}} 取分数。

8. 给缺失的小组创建列表，并把 '甲' 放进小组 '一班'。

## 综合题

9. 统计文本 'web ai web' 的词频，空输入应得空字典。

10. 按课程汇总学员 [('数学', '甲'), ('英语', '乙'), ('数学', '丙')]，组内保持原顺序。
