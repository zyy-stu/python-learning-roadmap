# Python 列表 list练习

通过终端输出或函数返回指定结果。题面给出固定输入时，先验证固定输入，再改变数据验证一般行为。

## 基础题

1. 创建从 0 到 3 的列表。

2. 取 [4, 8, 12] 的末项。

3. 将 3 添加到 [1, 2] 末尾。

4. 把 [1, 2, 3] 的第二项改为 9。

5. 从 [1, 2, 1] 删除首个 1。

## 进阶题

6. 从 [0, 1, 2, 3, 4] 取偶数的平方。

7. 将 [3, 1, 2] 降序排序，保留原列表。

8. 深拷贝 [[1]] 后修改副本中的值为 2，返回原值与新值。

## 综合题

9. 成绩 [62, 91, 48, 80] 筛出及格项并降序排列，空输入返回空列表。

10. 创建两行三列的独立网格，将第 0 行第 1 列设为 1。
