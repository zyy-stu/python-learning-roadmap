# Python 集合 set练习

通过终端输出或函数返回指定结果。题面给出固定输入时，先验证固定输入，再改变数据验证一般行为。

## 基础题

1. 把 [1, 1, 2] 转为升序去重列表。

2. 创建空集合并添加 'a' 后判断成员。

3. 计算两组 {1, 2} 与 {2, 3} 的并集并排序。

4. 求两集合 {1, 2} 与 {2, 3} 的交集。

5. 用 discard 删除不存在的 3，返回剩余集合。

## 进阶题

6. 返回 {1, 2} 和 {2, 3} 的对称差集。

7. 判断 {1} 是否是 {1, 2} 的子集，两集合是否不相交。

8. 使用冻结集合代表一组角色，并查询同一角色组合的权限。

## 综合题

9. 报名编号 {101, 102, 103} 与签到 {102, 103, 999}，返回缺席与未报名误签名单。

10. 对 ['甲', '乙', '甲'] 去重并保留第一次出现的顺序。
