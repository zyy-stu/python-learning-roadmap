# Python 数字类型

**适用 Python 版本** Python 3.11+

**难度等级** 基础

## 学习目标

- 解释数字类型的基本概念与运行行为。
- 运行配套示例并独立完成本篇练习。

## 前置知识

能在终端运行 Python 脚本。建议先学习[基本数据类型](02-data-types.md)。

## 基本概念

整数精确表示整数值，浮点数适合近似计算，复数用实部和虚部表示。金额计算常需要明确十进制舍入规则。

## 语法讲解

`0b1010`、`0o12`、`0xA` 都等于 10。`+ - * / // % **` 分别表示加减乘、真除、向下取整除法、余数和幂。整数输入的 `/` 返回浮点数，`int(float_value)` 则向零截断。比较用 `== != < <= > >=`，复数支持相等比较，不能排序。

## 代码示例

先运行这段代码。它演示如何把二进制文本 '1011' 转成整数。

```python
print(repr(int('1011', 2)))
```

## 运行结果

```text
11
```

这里使用 `repr()` 展示结果，便于识别字符串的引号和容器的边界。

## 常用方法

`abs()` 求绝对值或复数模，`round()` 舍入，`pow()` 求幂，`divmod()` 同时返回商和余数。`float()`、`int()`、`complex()` 可执行适用的转换。

## 工作原理

二进制浮点数无法精确表示很多十进制小数，因此 `0.1 + 0.2 == 0.3` 为假。`Decimal('0.1')` 从文本精确构造十进制值。`round()` 遇到精确中点取偶，金额规则可通过 `quantize()` 明确指定。

## 实际应用

将计价输入保留为十进制字符串。先计算总额，结算时按业务规则舍入到分。 从单个输入开始运行，再改变输入检查结果是否符合预期。

## 常见问题

为什么 `-7 // 3` 是 -3？整除向负无穷取整，余数满足 `a == (a // b) * b + a % b`。

## 易错点

`Decimal(0.1)` 会带入浮点数已产生的误差。近似浮点比较可用 `math.isclose()` 并选用合适的容差。
