# 统一质量门禁

每次新增或修改内容在 PR 中填写实际检查结果、日期、运行环境、命令、退出状态及对应提交。缺少环境时标记阻塞并给复现步骤。

## 教程

- 标题、目标、先修知识、概念与原理清晰。
- 代码与运行命令能复现，记录真实输出。
- 常见错误、练习与答案相匹配。
- 上下篇、引用、图片与版本链接已核对。

## 项目

- 需求、架构、依赖、配置、数据位置与命令一致。
- 独立安装与正常、失败、边界路径经过测试。
- 临时数据隔离，凭据和敏感数据经过审查。
- Ruff、格式检查、pytest 与适用 CI 完成。
- 实际提交可追溯，远程文件回读一致。

## 发布判断

规划、已交付、已验证分别注明。GitHub Actions 记录关联被验证的 SHA。远程文件存在与 CI 通过仅证明对应检查结果。验收报告需列出未验证项。
