学习路线

从最符合你当前能力的阶段开始，用完成目标检验学习成果。

入门

从零写出 Python 程序

先掌握变量、容器和流程控制，再用函数、文件与异常处理组织小程序。

完成目标　完成一个能持久化数据、能处理无效输入的命令行工具。

进阶

把程序做成可维护的应用

用模块和类型注解组织代码，学习数据模型、迭代器和测试，再接入数据库。

完成目标　交付一个有类型注解、数据库和自动化测试的小应用。

深入

掌握运行机制并交付项目

按项目需求学习并发、异步、内存管理与性能分析，再深入一个应用专题。

完成目标　交付可测试、可部署的项目，并记录性能或架构取舍。
