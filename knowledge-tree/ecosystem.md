# Python 技术生态

## Web 开发

- 先理解 HTTP 请求、响应、路由、状态码和请求校验。
- 再按项目需要学习 FastAPI、Django 或 Flask。从一个带验证的接口开始，随后加入数据库和测试。
- 数据方面先学关系数据库和事务，再接触 SQLAlchemy。理解键值访问和缓存过期后学习 Redis，理解文档建模后学习 MongoDB。

[Web 教程仓库](https://github.com/zyy-stu/python-web)

## 数据分析

- 用 NumPy 理解数组、形状、索引、向量化和广播。
- 用 Pandas 读取表格、处理缺失值、连接并分组汇总。
- 用 Matplotlib 表达趋势、分布和比较，并标注变量和单位。

[数据分析教程仓库](https://github.com/zyy-stu/python-data-science)

## 人工智能

- 先学习数据划分与评估，用 PyTorch 理解张量、自动求导和训练过程。
- 使用 Transformers 加载模型与分词器，完成可复现的推理。
- 在大语言模型应用中，先验证提示与评估集，再学习 RAG 检索和引用、AI Agent 工具调用和失败处理。

[AI 教程仓库](https://github.com/zyy-stu/python-ai)

## 工程化

- Git 管理源码和评审流程。
- pytest 验证成功与失败用例，Ruff 在提交前执行静态检查。
- Docker 固化运行环境，CI/CD 自动执行检查和后续交付流程。

[高级教程仓库](https://github.com/zyy-stu/python-advanced) · [代码规范](../standards/code-standard.md)
