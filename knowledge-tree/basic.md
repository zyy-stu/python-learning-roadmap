# 01 Python 基础

- **Python 入门与开发环境**
  - 认识解释器、脚本和交互式终端。
  - 安装 Python、选择编辑器、创建虚拟环境。
- **基础语法**
  - 缩进、表达式、变量和命名。
  - 数据类型、数字、布尔值、类型转换和字符串。
- **数据结构**
  - 列表与元组，掌握索引、切片和可变性。
  - 集合与字典，掌握去重、成员判断和按键访问。
- **流程控制**
  - 条件、循环、遍历和推导式。
- **函数、模块与包**
  - 参数、返回值和作用域。
  - 导入、入口、模块和包的组织。
- **文件操作与异常处理**
  - 路径、编码、文本、CSV 和 JSON。
  - 识别错误、使用异常处理和资源清理。
- **面向对象与标准库**
  - 类、实例、属性、方法与组合。
  - 使用 pathlib、datetime、collections 等常用模块。

先能操作单个值，再用容器组织数据和用流程控制处理数据。熟悉函数后再拆分模块。掌握异常处理后，用文件读写任务验证资源清理。
