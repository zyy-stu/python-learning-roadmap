先从基础语法、容器、函数和模块开始，再学习对象与迭代协议。应用方向各有前置知识。Web 需要 HTTP，数据分析需要表格处理与统计基础，AI 需要数据处理与模型评估基础。工程化随项目规模逐步引入，可先学习 Git 和测试，再学习容器和持续集成。

新增知识点时，选择所属分类，补充直接前置知识及专题仓入口。需要调整学习顺序时，同步修改[学习路线](../roadmap/README.md)。
