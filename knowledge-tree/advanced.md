# 02 Python 高级

- **Python 数据模型**
  - 通过魔术方法参与属性访问、容器操作、比较和调用。
  - 在掌握类与属性后学习描述符、类创建与元类。
- **函数与迭代机制**
  - 先理解作用域和闭包，再学习装饰器。
  - 从可迭代对象和迭代器入手，再学习生成器和生成器表达式。
  - 结合异常和资源生命周期理解上下文管理器。
- **解释器与运行时**
  - 区分语言约定与 CPython 实现细节。
  - 学习对象引用、内存管理和垃圾回收。
- **并发编程**
  - 理解线程、同步、共享状态和多进程通信。
  - 掌握事件循环、异步编程、取消和超时。
- **性能与类型系统**
  - 先度量运行时间和内存，再分析瓶颈并验证优化结果。
  - 从函数类型注解进阶到泛型、协议和静态检查。
- **工程化**
  - 组织包和依赖，编写测试，以 Ruff 和 CI 检查改动。

建议先完成[基础知识](basic.md)中的面向对象、函数和异常处理，再进阶到对象协议或并发。
