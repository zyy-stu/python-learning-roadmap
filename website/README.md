# 网站建设规划

1. **GitHub 与 Markdown**。先维护七仓导航、知识树和可运行的教程内容，统一目录、链接、文档结构与版本说明。
2. **MkDocs Material 文档网站**。用一组内容验证 Markdown 构建、跨仓导航、移动端阅读和全文搜索。记录断链、构建耗时和课程入口可达性。
3. **Vue 3 与 TypeScript 独立学习平台**。依据文档站收集的学习需求，逐步实现交互式知识树、教程阅读、全文搜索、用户登录和学习进度。后续扩展在线练习、在线代码运行和 AI 学习助手。

当内容能稳定构建和维护时进入文档站阶段。独立平台沿用既有知识分类与文章标识，便于迁移教程链接与学习记录。
