# Git 提交规范

提交主题使用 `类型: 简短说明`，一个提交聚焦一个可独立审核的改动。主题以动作开头，必要时在正文说明背景、范围和验证方式。

| 类型 | 用途 | 示例 |
| --- | --- | --- |
| `docs` | 教程、导航或说明 | `docs: 补充字典遍历教程` |
| `feat` | 新示例、新功能 | `feat: 添加 CSV 汇总示例` |
| `fix` | 修复错误 | `fix: 修复空数据统计` |
| `test` | 增加或调整测试 | `test: 覆盖缺失文件的处理` |
| `refactor` | 调整内部结构 | `refactor: 提取输入校验函数` |
| `chore` | 工具配置和日常维护 | `chore: 更新 Ruff 配置` |

提交前检查改动的文件、附带资源及测试结果，移除本地配置和临时产物。
