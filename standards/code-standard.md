# 代码规范

以 Python 3.11+ 为基础环境。框架教程应同时标注已验证的 Python 和依赖版本。

- 遵循 PEP 8，命名明确，函数职责单一。公共接口优先提供类型注解。
- 使用 Ruff 检查代码和格式。在已配置的专题仓库运行 `ruff check .` 与 `ruff format --check .`。
- 使用 pytest 验证正常输入、边界输入和可预见的失败。提供测试配置的仓库运行 `python -m pytest`。
- 注释与文档字符串使用中文，说明意图、约束或返回值。用清晰代码表达显而易见的操作。
- 示例可独立运行。文档提供依赖安装、运行目录、命令和预期结果。可执行脚本用 `if __name__ == "__main__":` 保护入口。
- 捕获可处理的具体异常，提供有用错误信息。测试与示例使用公开样例或合成数据。
- 提交前实际执行示例和适用检查，记录环境、命令与结果。
