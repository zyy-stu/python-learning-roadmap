# 初学者路线

## 学习目标

独立编写、运行和调试能处理文件的 Python 小程序。

## 前置知识

能使用文本编辑器和终端。首次使用终端时，先练习切换目录、查看文件与运行命令。

## 学习顺序

1. 安装 Python，创建虚拟环境，运行第一个脚本。
2. 学习变量、表达式、数字、字符串和基本类型转换。
3. 使用列表、元组、集合和字典组织数据。
4. 用条件和循环实现筛选、累计与校验。
5. 用函数拆分处理逻辑，用模块组织代码。
6. 读写文本或 CSV，处理路径不存在、输入不合法等异常。
7. 完成一个命令行项目并编写运行说明。

## 推荐实战任务

制作命令行记账工具。能够追加记录、读取历史 CSV、按类别汇总。用两组输入演示正常行为和错误提示。

## 阶段完成标准

- 从空目录创建并运行脚本。
- 能解释容器选择、函数参数和返回值。
- 能处理缺失文件和非法输入，并提供可复现的运行示例。
