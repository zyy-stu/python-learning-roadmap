# 中级路线

## 学习目标

将可运行脚本整理成职责清晰、带类型与测试的小应用。

## 前置知识

能使用基础容器、函数和模块，能独立读写文件与处理异常。

## 学习顺序

1. 学习类、对象与组合，用类型注解描述接口。
2. 理解迭代器、生成器、闭包和装饰器，按场景使用。
3. 掌握 pathlib、datetime、logging 等常用标准库。
4. 学习表、主键、查询和事务，使用 SQLite 保存数据。
5. 用 pytest 覆盖正常与失败路径，使用 Ruff 检查代码。
6. 用 Git 管理变更，整理依赖、运行说明和模块边界。

## 推荐实战任务

实现带 SQLite 的图书借阅程序，将业务逻辑与存储拆为模块，为借出、归还、重复借出和不存在的记录编写测试。

## 阶段完成标准

- 能解释迭代协议和装饰器的适用场景。
- 能编写带类型的公共接口并验证失败路径。
- 其他学习者可根据说明安装依赖并重现测试。
