# 学习路线

| 从哪里开始 | 路线 | 阶段交付 |
| --- | --- | --- |
| 能使用电脑和编辑器，刚开始编程 | [初学者](beginner.md) | 可重复运行的命令行工具 |
| 能用函数和模块完成小程序 | [中级](intermediate.md) | 带类型、持久化和测试的小应用 |
| 能组织并测试一个 Python 应用 | [高级](advanced.md) | 可部署、可复现实验或面向实际使用的项目 |

先看每条路线的前置知识，再按[知识树](../knowledge-tree/README.md)回查薄弱环节。每次学习用可运行示例验证理解，用阶段项目验证能否独立应用。
