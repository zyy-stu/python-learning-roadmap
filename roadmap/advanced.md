# 高级路线

## 学习目标

理解 Python 内部机制，在一个应用方向完成可验证的综合交付。

## 前置知识

已完成中级路线，熟悉对象、类型、数据库基础与测试。

## 学习顺序

1. 研究对象协议、描述符、元类和类创建过程。
2. 了解对象生命周期、引用关系及垃圾回收。
3. 区分线程、进程与异步 I/O，并用实验选择并发方案。
4. 先采样或计时，再优化热点，保留基线和对照数据。
5. 按目标选择 Web 框架、数据分析或 AI 开发方向。
6. 完成中大型项目，组织模块、测试、配置、部署与运行记录。

## 推荐实战任务

实现一个异步数据处理服务。记录吞吐与延迟，验证超时、取消和错误传播，并提供可复现的部署和测试说明。也可选择可复现的数据报告或带评估的 AI 应用。

## 阶段完成标准

- 用最小示例解释选用的对象机制或并发模型。
- 用数据验证至少一项性能或质量改进。
- 第三方能按文档启动项目、运行测试并重现主要结果。
